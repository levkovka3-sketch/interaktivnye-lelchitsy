# Интерактивные Лельчицы

Первый демонстрационный вариант сайта для проекта «Интерактивные Лельчицы» — цифрового дополнения к районной газете «Светлае жыццё».

## Файлы
- `index.html` — структура и тексты сайта.
- `styles.css` — оформление и адаптация под телефон.
- `script.js` — простые действия фотозагадки и демонстрационного опроса.
- `images/logo-szh.webp` — предоставленный логотип газеты.

## Важно
- Опрос пока демонстрационный: ответы не сохраняются и не отправляются редакции.
- Фотографии разделов «Угадай Лельчицы!», «Тогда и сейчас» и первой полосы выпуска пока являются местами для будущих материалов.
- Перед публикацией проверьте ссылки на официальные социальные сети.
- Не добавляйте полный PDF-выпуск газеты.

## Предварительный просмотр
Откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий GitHub, например `interaktivnye-lelchitsy`.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `script.js`, `README.md` и папку `images`.
3. В репозитории откройте **Settings → Pages**.
4. В разделе сборки выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохраните.
5. Подождите завершения публикации и откройте адрес, показанный в разделе Pages.

Сначала можно открыть сайт локально и проверить его. Не вводите в код пароли, секретные ключи или токены.
